# Fast File Search 操作ガイド

ファイル検索・サイズ集計・重複名検索・SHA-256比較を1つにまとめたRust製デスクトップアプリです。Windows向けの日本語GUIで操作できます。

## 起動

配布ZIPを利用する場合は、展開先の `Fast_File_Search.exe` を起動してください。ソースから通常ビルドした場合は `target/release/Fast_File_Search.exe` に生成されます。Windows標準の日本語フォントを使用します。

ソースからビルドする場合はRust 1.92以上とWindowsのMSVCビルド環境を用意し、次を実行します。初回は依存ライブラリの取得が必要です。

```powershell
cargo build --release --locked
.\target\release\Fast_File_Search.exe
```

開発中は `cargo run --locked` でも起動できます。

## 使い方

1. 左側で機能を選択します。
2. フォルダまたはファイルを選択して追加します。複数選択、繰り返し追加、パスの直接入力が可能です。サイズ集計は1フォルダのみで、追加すると対象を置き換えます。
3. 必要な検索条件を入力し、並列処理またはシングルスレッドを選びます。
4. 「実行」を押します。処理中は進捗を表示し、「中止」で途中までの結果を表示できます。
5. 結果の並び替え、ファイル名クリックによるパス・SHA-256のコピー、CSV保存ができます。

| 機能 | 対象 | 動作 |
| --- | --- | --- |
| ファイル名検索 | 1つ以上のフォルダ | 拡張子を含むファイル名の部分一致。空欄は全ファイル。ワイルドカード・正規表現には非対応 |
| ファイルサイズ集計 | 1つのフォルダ | 全ファイルのサイズと合計を表示。初期表示はサイズ降順 |
| 拡張子検索 | 1つ以上のフォルダ | `pdf, .txt, *.jpg` のように指定。カンマ・空白・セミコロン・読点で区切る |
| 重複ファイル名検索 | 1つ以上のフォルダ | 拡張子も含む同名ファイルを2件以上のグループで表示。ファイル内容は比較しない |
| SHA-256比較 | 2つ以上のファイル | 各ファイルのSHA-256と、すべて一致するかを表示 |

## 対象範囲と処理方式

- 全フォルダ機能は再帰的にサブフォルダを探索し、隠しファイルも含めます。
- ファイル名・重複名検索は大文字小文字を区別するか選択可能。初期値は区別なしです。拡張子は常に区別せず、最後のドットより後を比較します（`archive.tar.gz` の拡張子は `gz`）。
- 親子フォルダ・同じフォルダの重複指定は正規化し、同じパスの二重集計を避けます。ハードリンクの異なるパスは別ファイルとして数えます。
- 指定ルートは実体パスに解決します。その配下のシンボリックリンク、ジャンクション、およびWindowsのその他の再解析ポイントはスキップします。クラウドプレースホルダー等も対象外になる場合があります。
- サイズはファイルの論理バイト数です。ディスク上の使用量、フォルダ自体のサイズ、代替データストリームは含めません。重複名検索の合計は表示されたファイルの合計であり、削減可能容量ではありません。
- 並列モードは専用のRayonスレッドプールでフォルダ単位の探索、またはファイル単位のハッシュ計算を行います。スレッド数は1〜64で指定でき、初期値は論理CPU数（上限8）です。単一フォルダにファイルが集中する場合や低速ストレージでは高速化しないことがあります。
- シングルスレッドモードでは処理用ワーカー1つだけで順次処理します。どちらの方式もGUI描画とは別スレッドで動作します。
- SHA-256は1 MiBずつ読み込むため、大きなファイル全体をメモリには読み込みません。読込前後のサイズ・更新日時に変更があればエラーとして扱います。ファイルシステムのスナップショットは取得しないため、比較対象は編集を止めてから実行してください。
- 無効な指定パスは実行時にエラー表示します。探索・読込中のエラーは件数と詳細（最大200件）を表示します。中止・エラーのあるSHA-256比較では、全体一致の判定を出しません。
- 中止は各ディレクトリエントリ／読込ブロックの間で確認します。応答しないネットワークドライブ等のOS入出力待ちを強制中断するものではありません。
- 結果一覧は画面内の行だけ描画しますが、結果データと探索待ちのフォルダはメモリに保持します。
- CSVはUTF-8 BOM付きで、バイト単位のサイズ、グループ、ハッシュ、完了／部分結果の状態を出力します。数式として解釈される名前には先頭に `'` を付けます。

## 検証

```powershell
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
cargo fmt --check
```

並列・単一スレッドの結果一致、複数ルート・親子重複、再帰探索、日本語ファイル名、拡張子、重複名、既知のSHA-256、複数読込ブロック、中止、入力エラー、ジャンクションの循環回避、CSVをテストします。

## 実装

- `src/app.rs`: egui/eframe GUI、ファイル選択、処理スレッド、結果表示
- `src/engine.rs`: 検索・集計・ハッシュ比較エンジン
- `src/export.rs`: CSV出力
- `tests/engine.rs`: ファイルシステムを使った統合テスト

利用API: [eframe 0.33](https://docs.rs/eframe/0.33.0/eframe/)、[rfd 0.15](https://docs.rs/rfd/0.15.4/rfd/)、[Rayon](https://docs.rs/rayon/)、[SHA-2](https://docs.rs/sha2/)。
