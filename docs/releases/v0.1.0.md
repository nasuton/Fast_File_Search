# Fast File Search v0.1.0

日本語GUIでファイル検索・容量確認・SHA-256比較を行うWindows向けデスクトップアプリの初回リリースです。

## 機能

- 複数フォルダのファイル名・拡張子検索、重複ファイル名のグループ表示
- 単一フォルダ配下のファイル別サイズと合計
- 複数ファイルのSHA-256計算・比較
- 並列／シングルスレッドの選択、進捗表示、中止、CSV保存

## インストール

`Fast_File_Search-v0.1.0-windows-x86_64.zip` をダウンロードして展開し、`Fast_File_Search.exe` を起動してください。Rustのインストールは不要です。日本語表示にはWindowsのメイリオ／游ゴシックを使用します。

ZIPには利用ガイド、MITライセンス、依存ライブラリ・内蔵フォントのライセンス一覧を同梱しています。`.zip.sha256` はZIPの整合性確認用です。

## 制限

- Windows x86_64向けです。コード署名は行っていません。
- 重複名検索は内容を比較しません。内容の確認にはSHA-256比較を使ってください。
- 配下のリンク・ジャンクション・再解析ポイントは探索対象外です。
- サイズは論理サイズです。並列化の効果はストレージと構成に依存します。
- 大量の結果のソート・CSV保存と、応答しないストレージの入出力待ちは即時中断できません。
